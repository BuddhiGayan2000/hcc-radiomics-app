# Quick Start: Test HCC 010 Dataset

**Time:** 30 minutes | **What You'll Do:** Upload images → Draw ROI → Extract features → Check predictions

---

## What You Have

```
HCC 010 final/
├── DATA HCC 010/                          ← 20 pre-contrast DICOM slices
├── FEATURES HCC 010/
│   └── HCC_010_tumor_features.csv         ← Ground truth (25 features × 4 slices)
│   └── Slice_neg*.overlay.png             ← Visual guides (where to draw ROI)
└── SAME SLICE LOCATION HCC 010/          ← Reference images
```

---

## 5-Minute Setup

### 1. Start Servers (Terminal 1 & 2)
```bash
# Terminal 1: Backend
cd backend && python -m uvicorn app.main:app --host 127.0.0.1 --port 8000

# Terminal 2: Frontend  
cd frontend && npm run dev
```

### 2. Convert DICOM → PNG
```bash
# Terminal 3
pip install pydicom pillow numpy
python scripts/convert_dicom_to_png.py --slices 10 12
```

This creates 2 PNG files in `data/test_images/` ready to upload.

### 3. Open Web App
Open http://localhost:5173 in your browser.

## Testing Workflow (20 minutes)

| Step | Action | Expected Result |
|------|--------|---|
| 1 | Click **"Upload Pre-Contrast Image"** | Image displays in canvas |
| 2 | Open overlay image (`Slice_*_overlay.png`) to see tumor location | Red outline shows where to draw |
| 3 | **Draw ROI** on the tumor, matching the overlay boundary | Polygon appears on image |
| 4 | Click **"Extract Features"** | 25 feature values appear in table |
| 5 | **Compare with CSV** — Open `HCC_010_tumor_features.csv`, find matching slice, compare values | ✓ Values should match ±10% |
| 6 | **View predictions** — BCLC stage + necrosis probabilities appear | ✓ Stage probabilities sum to 1.0 |
| 7 | **Check SHAP evidence** — If not GradientBoosting, top 5 features appear | ✓ Shows which features influenced prediction |

---

## Success Criteria

✓ **PASS** if:
- Feature values match CSV ±10% (morphology ±5%)
- All 25 features have numeric values (no NaN)
- Stage predictions are valid probabilities (0–1, sum ≈ 1.0)
- No API errors in browser console

⚠️ **MINOR ISSUES** (expected):
- Differences 5–10% (due to ROI drawing variation)
- GradientBoosting has no SHAP explanation (known limitation)

✗ **FAIL** if:
- Differences >15% (suggest ROI error or feature extraction bug)
- Any NaN/infinity values
- API errors: "Cannot connect to localhost:8000"

## Troubleshooting

| Problem | Check | Fix |
|---------|-------|-----|
| "API Unreachable" | `curl http://localhost:8000/health` | Kill Python, restart backend |
| Image doesn't show | Check PNG is valid, not corrupted | Re-convert DICOM |
| ROI drawing is slow | Image is large (>2048×2048) | Use Chrome, resize image |
| Features all zero/NaN | Check browser console (F12) | Verify ROI is within image bounds |
